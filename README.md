# Apex Power LLC

Standalone website for [Apex Power LLC](https://apexpowerllc.org/).

## Publishing

This repository is prepared for GitHub Pages:

- Publish from the repository's default branch and root folder.
- Use `apexpowerllc.org` as the custom domain.
- Preserve the domain's existing Microsoft 365 MX records when updating website DNS.
- Enable **Enforce HTTPS** after GitHub provisions the certificate.

The site is fully standalone.
